## 建议优先写的三本

| 顺序 | 建议书名 | 目标读者与核心问题 | 与已有书的区别 | 拟开展的真实实验 |
| --- | --- | --- | --- | --- |
| 1 | Kubernetes 控制器与 Operator 工程：从协调循环到可靠运维 | 已会部署应用的后端、Go 开发者；如何让系统持续收敛到声明的状态 | Kubernetes 入门回答如何使用资源，Go 书关注单服务资源与生命周期；本书解释控制器如何观察、决策和修复漂移 | 在 kind 中实现托管网关实例控制器，验证重复 reconcile、外部修改、冲突重试、控制器重启、finalizer 清理、状态条件及 CRD 升级 |
| 2 | 业务数据同步工程：从 CDC 到可重建索引 | 已会数据库和消息的后端开发者；业务数据变化怎样可靠进入查询系统 | MySQL 书关注源事务，Kafka 书关注日志和消费，检索书关注索引；本书连接三者，处理快照与增量交接、位点、删除和重建追平 | 真实 MySQL 变更日志经 CDC、Kafka 进入查询投影，验证快照期间写入、重复消费、删除、消费停机、模式变化和全量重建；与源数据逐项对账 |
| 3 | MySQL 备份、复制与恢复演练：从数据保护到故障切换 | 已会 SQL 和事务的业务开发、运维人员；怎样证明备份能恢复、隔离旧主并验证切换流程的写入边界 | 现有 MySQL 书关注事务隔离、锁和业务并发，本书关注实例与数据生命周期 | 搭建真实主从复制，注入复制延迟与连接故障；在独立实例恢复备份、回放 binlog 至目标点、隔离旧主并核对切换前后数据；记录条件明确的 RPO/RTO |

三本分别延伸现有 Go/Kubernetes、MySQL/Kafka/检索、数据库可靠性路线，读者前置基础清楚，也能持续积累可复用实验。建议每本围绕一个贯穿全书的工程，而不是按工具清单拼接章节。

### 第一优先：Kubernetes 控制器与 Operator

这是与现有 Go、Kubernetes、网关工程积累连接最自然的选题。主线应是期望状态、实际状态、协调循环和删除生命周期。Go 语法、Deployment 入门、网关基础都可以引用既有书，不再展开。

最小项目可以选择托管网关实例控制器：自定义资源描述期望配置，控制器管理 Deployment、Service 与状态条件。先实现单个控制器实例，再分别验证重启、重复事件、资源冲突和失效清理。只有完成多副本实验后才讨论该实现的主选举保证，不能把 client-go 的 API 使用等同于已验证高可用。

### 第二优先：业务数据同步

这本可以让已有 MySQL、Kafka、知识库读者继续完成一个跨系统项目：源库发生变化，查询投影最终可对账并能从头重建。需要明确快照与增量交接的边界、偏移量提交和投影更新的关系，以及删除、重复事件和模式变化的处理方式。

最小项目可采用 MySQL → CDC 连接器 → Kafka → 查询投影。先选一种投影存储，把正确性与重建讲透；不同时横向介绍多种搜索和向量数据库。验收应比较源记录和投影结果，而不仅检查消息条数。这里的“可重建”也不等于业务事务与整个数据链路构成同一个原子提交。

### 第三优先：MySQL 恢复演练

这本应围绕“恢复后究竟有哪些数据”组织，覆盖备份可用性、恢复点、GTID 与复制位置、延迟、切换和旧主隔离。每个主要实验都应恢复到干净实例并核对业务不变量，不能只验证备份文件存在、复制线程运行或配置语法正确。

异步复制和切换条件必须写清楚；RPO/RTO 是指定环境、故障与恢复流程下的测量，不应转述为产品保证。本机没有 MySQL 容器环境时，需要在 Linux CI 中运行真实多实例实验并保留日志。

浏览器方向如果提前启动，建议以可重置的教学业务网站开展动态 DOM、弹窗、过期会话、重复提交和结果未知实验。确定性 Playwright 回归与真实模型规划实验应分别记录，不能将脚本通过率写成自主 Agent 成功率。已有持久执行和授权机制可以引用，新增篇幅集中处理网页交互特有的问题。

这轮不优先另开通用 PostgreSQL 入门、又一本 RAG 入门或新的编程助手源码导读。它们并非没有价值，但当前书架更需要能接到现有路线末端、解释新故障模式的专题。

## 与新书并行的旧书升级

1. **Agent 记忆扩写**：从研究与设计推进到可运行系统，补充写入筛选、来源与时效、冲突、遗忘与删除传播、用户隔离及长期任务评测。延续原书定位与入口，发布新版，不重复新增书卡。
2. **Sandbox 实验升级**：增加恶意或失控工作负载、资源上限、网络限制和清理失败实验。严格区分 Docker 教学隔离与内核或虚拟机级隔离；没有对应运行证据的技术保留为设计讨论。

建议顺序：先完成当前三本及 26 本书架的发布收尾，再依次推进 Operator、CDC 数据同步、MySQL 恢复；若下一轮更侧重 Agent 应用，可将浏览器 Agent 提前。记忆与 Sandbox 作为旧书改版安排。后续选题与当前交付分别记录，避免把分析建议误当成已授权的新一轮写作任务。
